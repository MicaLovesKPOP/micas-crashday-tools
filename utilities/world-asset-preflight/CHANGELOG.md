# World Asset Preflight v0.2

- Read-only CFL/VEG dependency checker for loose content and ZIP-based packages.
- Explicit references; case-insensitive asset resolution and SHA-256 ambiguity checks.
- Self-contained, direct and transitive strict dependency modes.
- Nonsequential/repeated vegetation headings retain all articles in file order.
- Opt-in native CFL CRLF framing, including reachable external CFLs.
- Reject symlink archive entries and unsupported model/definition reference scopes.
- Python 3.7+; standard library; JSON and human-readable output.

Does not certify native game loading, P3D geometry or collision, TEX/materials, or implicit mod priority.
