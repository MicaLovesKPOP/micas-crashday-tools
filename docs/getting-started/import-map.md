# Import a Crashday map into Blender

[Getting started](../index.md) · [Downloads](../downloads.md)

1. Download and enable the Crashday to Blender Exporter from [Downloads](../downloads.md).
2. In Blender, choose File > Import > Crashday Track (.trk).
3. Select a TRK/TRK2 track and the installed game directory. If assets are ambiguous, choose the appropriate mod or Workshop item.
4. Inspect the imported collections and Import Report. Choose Save As and save a new Blender file.

The importer preserves original terrain height samples and imports editable models, textures, UVs, dynamics and source-constrained approximate vegetation. Large scenes can use substantial memory; use bounded/off vegetation preview when appropriate. Game-exact procedural vegetation and external scenery are not guaranteed.

Read the [Exporter guide](../../addons/crashday-exporter/) for current options and limitations. Original game and downloaded mod files are read-only.
