## Choose your workflow

### Create a map

1. Install the compatible Tile Splitter and World Builder versions from [Downloads](downloads.md).
2. Open a Blender scene containing your own geometry or geometry you have permission to use.
3. Follow the [map creation guide](getting-started/create-map.md) to prepare tiles, choose checkpoints and build a new offline map.

### Bring an existing Crashday map into Blender

Install the Crashday to Blender Exporter from [Downloads](downloads.md), then follow the [import guide](getting-started/import-map.md). Use your own installed Crashday files.

### Investigate an asset problem

Use the [inspection guide](getting-started/inspect-assets.md) to choose P3D Validator or World Asset Preflight. Neither requires Blender.
