# Roadmap

[Home](../README.md) · [Downloads](downloads.md)

## Released

Independent Crashday Exporter, Tile Splitter, World Builder, P3D Validator and World Asset Preflight. See the download catalog for exact versions, compatibility and limitations.

## Next focus — integrated map creation

Planned, not shipped: one-click non-destructive preparation of geometry and textures, content-based deduplication, safe native naming and format conversion, model/tile optimization, and a single coordinated map build. Checkpoints remain manually authored; editable native CFL areas and automatic previews are planned. Incremental rebuilding should avoid unnecessary work.

## Later opportunities

Independent environment generation, texture/material utilities, mod packaging, optional modern Blender Extensions packaging and navigation authoring may follow. AI runtime compatibility and breakable-object authoring are not requirements for the initial streamlined conversion milestone.

These are directions rather than dates or guarantees. Native format support must be verified; optional functionality does not hold up useful independent releases. Crashday Unleashed owns game-runtime changes; this repository contains offline tools.
