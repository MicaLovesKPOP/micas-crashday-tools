# Changelog

## 0.2.0 - 2026-11-25 (first public release)

- Ordered 20 m viewport checkpoint selection, native quarter-turn control and automatic marker synchronization.
- Offline Validate/Build, permission bits, route-free stock-start option, overhead preview binding and create-only output.
- Experimental multi-cell checkpoint carving and oversized anchor/void support.
- Adaptive sidebar and workflow ordering. Route metadata persists in Blender scenes.
- Native custom checkpoint headings, game-mode playability, advanced collision and interactive marker undo/redo remain unverified.
