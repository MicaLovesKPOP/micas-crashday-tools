# Crashday to Blender Exporter changelog

- Read-only TRK/TRK2 geometry, heightmaps, tile meshes, dynamics, supported
  textures/UVs, Workshop/mod asset selection and import provenance.
- Blender 2.80/2.83/3.4.1/4.5 technical acceptance; owner GUI 3.4.1
  import/Save As/reopen accepted.
- Seeded approximate CFL vegetation (native random generator not replicated).
- Optional default-OFF out-of-bounds scenery and detailed import diagnostics.
- GPL-2.0-only terms, pinned Wurunduk attribution, public quickstart and
  author metadata. Import implementation remains byte-identical to the frozen,
  owner-tested v0.1 source.
