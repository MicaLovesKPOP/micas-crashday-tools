# Mica's Crashday Tools

Independent community tools for **Crashday: Redline Edition**.
Tools have separately versioned releases, separate module licenses and standalone installation.

## Available now
- [P3D Validator v0.4.0](utilities/p3d-validator/) — read-only Python 3.7+
  P3D2 structure, bounds, archives and Tile Splitter manifest checker.
  Download it from the [Releases](https://github.com/MicaLovesKPOP/micas-crashday-tools/releases) page.

## Upcoming
- Crashday to Blender Exporter — privately tested, pending final GUI and Wurunduk-attribution review.
- Derived Tile Splitter — privately tested, pending native game and user acceptance.
- World Builder, World Asset Preflight, EnvGen and other modules when independently qualified.

Unreleased source is **not** present in this public repository. It stays in a
separate owner-only incubator until license, acceptance and rights reviews pass.
Each module has its own LICENSE/NOTICE and changelog; no blanket root license.
No copyrighted game assets, owner scenes or proprietary models are distributed.
